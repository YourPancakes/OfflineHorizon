# OfflineHorizon

**OfflineHorizon** is an unofficial, offline-oriented fork of [Horizon](https://github.com/horizon-rust/horizon), a Rust implementation of Minecraft: Java Edition 26.3 built with wgpu. This fork focuses on offline access and resource preparation. It is intended for educational and research purposes.

## Features

- **Offline mode:** Play using an offline player name without mandatory Microsoft sign-in.
- **Autonomous Minecraft download:** Download and prepare required Minecraft 26.3 client, assets, and libraries directly from Mojang servers when a network connection is available into the user application data directory.
- **Privacy & Telemetry:** All background telemetry, telemetry pings, and data collection are completely disabled.
